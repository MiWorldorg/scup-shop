# Security Policy

## Supported versions

Scup-Shop is a portfolio project under active development. Until a stable release is published, security fixes are handled on a best-effort basis for the current development branch.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in public issues.

For private reports, use GitHub's **Report a vulnerability** feature under the repository's Security tab if it is enabled. If private vulnerability reporting is unavailable, contact the repository owner through their GitHub profile and request a private reporting channel before sharing technical details.

Include:
- A concise description and potential impact.
- Affected component and version/commit.
- Steps to reproduce using a local or disposable environment.
- Any suggested mitigation, if known.

Avoid including personal data, real user credentials, or secrets in the report.

## Scope and expectations

- This project has no production deployment or stable release currently.
- Reports are reviewed as time and project status allow; no response-time SLA is promised.
- Do not test against third-party systems or attempt to access data that is not yours.
- Coordinated disclosure is appreciated; please allow time to investigate before public disclosure.
