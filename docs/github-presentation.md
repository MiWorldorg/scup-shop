# GitHub presentation guide

## Repository About description
A premium sculpture storefront and editorial platform built with Flutter, Laravel 13, and MySQL.

Suggested topics: `flutter`, `dart`, `laravel`, `php`, `mysql`, `getx`, `rest-api`, `laravel-passport`, `responsive-design`, `sculpture`, `art-gallery`, `digital-gallery`, `portfolio-project`.

## Visual direction
- Premium classical gallery mood, charcoal / near-black, warm ivory, sandstone and muted bronze.
- Artwork first, generous negative space, minimal decoration.
- Refined serif display typography paired with clean sans-serif supporting text.

## Social preview
Recommended canvas: **1280 × 640 px**. Use the Scup-Shop identity, charcoal background and bronze/stone accents, with only `SCUP-SHOP` and `A sculpture & editorial platform`. Keep elements inside the central safe area.

## Manual GitHub settings
1. Open the repository on GitHub.
2. In the **About** panel, choose the gear icon.
3. Paste the description and add the suggested topics.
4. Save.
5. Open **Settings → General → Social preview** and upload the image.

Keep the repository private while development, asset ownership, licensing, and release checks are incomplete.
