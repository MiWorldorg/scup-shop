**Title:** Scup-Shop — Responsive Flutter Storefront and Laravel API

**Short description (under 280 characters):**

Building Scup-Shop, a portfolio-focused sculpture storefront with Flutter, GetX, Laravel 13, Passport, and MySQL. The project includes a responsive catalog, editorial publishing, admin tools, and a configurable contact-email workflow.

**Skills:** Flutter, Dart, GetX, Laravel, PHP, REST API design, MySQL, responsive UI, API authentication, relational data modeling.
